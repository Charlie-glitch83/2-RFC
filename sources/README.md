# Canonical Source Manifest

`SOURCE_MANIFEST.json` identifies the five manuscript/metadata text sources used by this rebuild, including exact SHA-256 hashes, `1RFC` paths, and public URLs. Their evidentiary roles are recorded in `evidence/SOURCE_AUDIT.md`.

The large raw sources are not duplicated here. Fetch them from the locked location and verify the hash before use. Proposed corrections and derived theorems belong under `proofs/` and `science/`.
