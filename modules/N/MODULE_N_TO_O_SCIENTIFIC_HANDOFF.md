## Purpose

This file seals the boundary between the complete manifested physical universe assembled by Module N and the immutable scientific freeze owned by Module O.

It defines only:

- the exact physical state Module N must export;
- the conditions under which that state may be frozen;
- which identities, laws, fields, objects, events, records, memories, uncertainties, and restart variables Module O inherits unchanged;
- what Module O may establish about immutability, restoration, scientific equivalence, and branch identity;
- the exact separation between the read-only empirical child Module P and the continued-physics child Module Q;
- what information is forbidden from crossing among the parent and its children.

It does not import the former run system, run numbering, source-register bureaucracy, proof-obligation ledgers, gate taxonomy, certificate architecture, repository schema, lifecycle machinery, or evidence paperwork as scientific content.

```text
Q descendant state != mutable O parent

```
