# Module O → Module P Scientific Handoff

## Purpose

This file seals the read-only scientific boundary between the immutable RFC universe preserved by Module O and the blind empirical-comparison branch owned by Module P.

It defines only:

- the exact frozen parent identity Module P receives;
- the authorized truth, prediction, signature, uncertainty, ensemble, scope, and lineage interfaces;
- which observational constructions Module P may create;
- which public information may enter Module P and under what role;
- the one-way transition from frozen truth to observation-equivalent products and claim decisions;
- the absolute prohibition on mutation of Module O, Modules A–N, or Module Q;
- the exact scientific outputs of Module P and their lawful destinations.

It does not import the former run system, run numbering, source-register bureaucracy, lifecycle machinery, repository schema, gate taxonomy, certificate architecture, proof-obligation ledger, or evidence paperwork as scientific content.

---

# 1. Boundary statement

Module O owns the immutable parent universe.

Module P owns only the observation and comparison descendants of that parent.

The protected branch law is:

```text
N -> O -> {P,Q}
P -/-> O
P -/-> Q
Q -/-> O
```

The empirical chain is:

```text
frozen RFC truth
-> signal formation and propagation
-> instrument response
-> selection, masking, noise, and foreground effects
-> observation-equivalent map, catalogue, event set, or data vector
-> statistic and covariance
-> blind comparison
-> evidence-matched claim decision
```

Therefore:

```text
truth state != observed data product
observation operator != physical law
instrument nuisance != RFC physical parameter
statistical agreement != empirical validation
validation on existing data != predictive confirmation
public ranking != internal branch selection
discrepancy diagnosis != permission to retune
Module P evidence != Module Q physical input
```

---

# 2. Immutable parent

Module P receives no writable physical state.

Its parent is:

```text
U_O^parent = Freeze(P_N->O)
```

Module P may query authorized projections of this parent but may not alter:

- physical fields or objects;
- laws, constants, couplings, or validity domains;
- universe, cycle, branch, realization, or freeze-surface identity;
- random streams or ensemble weights;
- initial conditions or event histories;
- uncertainty or covariance;
- intrinsic signatures or falsifiers;
- claim text or physical scope;
- lineage, memory, or unresolved boundaries;
- Module Q restart state or terminal-facing variables.

A comparison result that motivates new theory requires a new A–N construction and a new Module O parent. It cannot revise this parent in place.

# 4. Conditions for Module P admission

Module P may begin only if:

1. the Module O parent identity is unique or the lawful branch family is explicit;
2. the read-only truth interface is sufficient for every declared probe;
3. truth observables retain source, propagation, units, convention, branch, and covariance state;
4. predictions, claims, intrinsic signatures, scopes, and falsifiers were frozen before public numerical comparison;
5. uncertainty and covariance are complete enough for the declared decisions;
6. ensemble, realization, and observer-location rules were frozen before comparison;
7. all unresolved physical and observation-interface limits are explicit;
8. the Module P child has no write path to the parent or Modules A–N;
9. the Module P child has no dependency or export path to Module Q;
10. no public result was used to select the parent, branch, realization, normalization, signature, or claim wording.

A missing truth field is a Module N or O defect. Module P may not reconstruct it from public data or conventional best-fit cosmology.

# 7. Public-data entry boundary

Public or independently held evidence may enter only Module P.

For every declared claim, each dataset must receive one primary role:

```text
calibration
validation
prediction
benchmark
```

with these meanings:

- **calibration**: permitted only for explicitly observational interface quantities and never for RFC physical source laws;
- **validation**: independent data used for preregistered testing;
- **prediction**: withheld, future, or otherwise uninspected when the prediction and decision rule were frozen;
- **benchmark**: used to test an observation or comparison method, not to validate RFC physics.

Dataset role may vary by claim only when leakage is explicitly excluded.

- evidence-matched claim decisions.

These constructions describe how frozen truth would be observed. They are not new universe physics.

# 10. Observation-model nuisance boundary

A parameter may be inferred inside Module P only when:

1. it belongs to the instrument, survey, foreground, calibration, selection, or measurement model;
2. its physical meaning is observational rather than generative;
3. its admissible range or prior is fixed before residual inspection;
4. its uncertainty is propagated;
5. the same method is applied to appropriate benchmarks where required;
6. it cannot alter Module O truth;
7. its estimate is not exported to Module Q.

An upstream physical quantity may not be relabeled as an observational nuisance to permit fitting.

# 11. One-way observation map

For each probe `p`, Module P constructs:

```text
D_p^syn
= S_p o N_p o I_p o L_p(U_O^parent)
```

where:

- `L_p` forms and propagates the physical signal;
- `I_p` applies instrument response;
- `N_p` applies noise, foreground, contamination, and systematic state;
- `S_p` applies selection, catalogue or map formation, and statistic construction.

The layers remain distinct:

```text
Truth_p -> Signal_p -> Observed_p -> Statistic_p
```

A discrepancy must be localized to the correct layer before its scientific meaning is assigned.

# 12. Information-loss boundary

Every observation path must classify truth information as:

```text

selection-biased

```

A claim may not demand information that the instrument and observation process cannot retain.

An inconclusive result caused by non-identifiability is not automatically a physical failure.

# 13. Preregistration and unblinding boundary

Before inspecting RFC-versus-data residuals, Module P must freeze:

- parent universe and branch identity;
- claims and primary endpoints;
- eligible datasets and their roles;
- scale, time, redshift, population, frequency, environment, and event domains;
- truth-to-observation operator;
- binning and estimator;
- covariance and systematics model;
- nuisance rules;
- mandatory conditions and normalized score definitions;
- falsifiers;
- multiplicity and look-elsewhere treatment;
- missing-data and outlier rules;
- unblinding order;
- independent replication requirements.

Once fully unblinded, the same claim, parent, dataset release, and analysis cannot be returned to blind status.

Post-unblinding work must be labeled diagnostic, exploratory, or a new frozen comparison. It cannot replace the original decision.

# 14. Ensemble, branch, and observer rules

Module P must compare public reality with the frozen Module O ensemble and branch state.

It may report:

- unconditional universe distributions;
- lawful branch-conditioned distributions;
- declared observer-conditioned distributions;
- cosmic and finite-volume variance;
- rare-event probabilities;
- environmental dependence.

It may not select the most favorable realization, branch, environment, location, seed, orientation, scale, epoch, or population after inspection unless that selection rule was frozen and physically justified.

Public ranking of authorized branches may be reported. It may not retroactively delete or reweight the parent branch family.

---

# 15. Sibling isolation

The required dependency statements are:

```text
Writes(P,U_O^parent) = empty
Deps(Q) intersect Artifacts(P) = empty
```

Module P may not send to Module Q:

- public data;
- residuals;
- likelihoods;
- fitted nuisance values;
- empirical branch rankings;
- claim decisions;
- validation or falsification outcomes;
- post-unblinding diagnostics;
- proposed physical repairs.

Any detected path invalidates the affected empirical claim and blocks the contaminated Q descendant.

---

# 16. No-retune boundary

Module P may not:

- change the triad, First Action, or kernel;
- change a law, constant, source, or interface classification;
- alter a physical parameter;
- rescale an amplitude or normalization;
- select a new seed or realization;
- delete a physical branch;
- replace the uncertainty model with a favorable one;
- alter the comparison scope after seeing residuals;
- drop an unfavorable probe without a frozen rule;
- redefine a falsifier;
- alter Module Q terminal physics.

A diagnostic explanation may guide a future research program, but the frozen parent and original result remain unchanged.

# 20. Forecast preservation and successor boundary

Every preregistered target must remain preserved with:

- original prediction;
- original uncertainty;
- original claim and scope;
- public data release;
- observation operator;
- result;
- empirical status;
- later release comparisons;

A successor RFC construction motivated by this evidence must:

1. leave the original Module O parent and Module P result unchanged;
2. identify a new internal scientific justification;
3. rebuild the affected physical chain;
4. receive a new Module O identity;
5. treat the motivating evidence as development data;
6. require new held-out or independent evidence for confirmation.
